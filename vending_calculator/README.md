## Калкулатор за възвръщаемост на вендинг автомат

Самостоятелно Python/Flask уеб приложение, което изчислява:

- **Срок за изплащане** на вендинг/кафе автомат (в месеци и години)
- **Дневна, месечна и годишна печалба**
- **Марж на печалбата** на една напитка

Всичко работи като една страница с модерен, тъмен интерфейс, подходяща за **вграждане в блог като widget**.

---

### 1. Изисквания

- Python 3.10+ (препоръчително)

---

### 2. Инсталация

Отворете терминал в директорията на проекта и изпълнете:

```bash
cd vending_calculator
python -m venv .venv
.venv\Scripts\activate  # Windows PowerShell / cmd

pip install -r requirements.txt
```

---

### 3. Стартиране на приложението

```bash
cd vending_calculator
.venv\Scripts\activate
python app.py
```

По подразбиране приложението се стартира на:

- `http://127.0.0.1:8000/`

---

### 4. Вграждане в блог (iframe)

След като го качите на сървър (примерно `https://example.com/vending/`), можете да го вградите в блог пост чрез:

```html
<iframe
    src="https://example.com/vending/"
    width="100%"
    height="650"
    style="border: none; max-width: 1080px; margin: 0 auto; display: block;"
    loading="lazy"
></iframe>
```

По желание може да променяте височината (`height`) според нуждите на темплейта на блога.

---

### 5. Какви параметри използва калкулаторът

Въвеждате:

- **Цена на автомата** – начална инвестиция.
- **Брой напитки на ден** – среден дневен обем.
- **Продажна цена / напитка** – колко струва една напитка на клиента.
- **Консумативи / напитка** – себестойност (кафе, захар, мляко, чаши и др.).
- **Разход за ток на ден** – ориентировъчен дневен разход за електроенергия.
- **Месечни фиксирани разходи** – части, сервиз, наем на място и др.

Моделът приема:

- 30 дни в един месец (за опростяване);
- **месечна печалба = (дневна печалба × 30) – месечни фиксирани разходи**;
- **срок за изплащане = цена на автомата / месечна печалба** (ако печалбата е > 0).

Резултатите са ориентировъчни и **не заменят детайлен финансов анализ**, но дават бърза и удобна първоначална оценка.
